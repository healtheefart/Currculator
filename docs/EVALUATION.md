## 안정성 확인

- 배포 API 실측: 빈 URL은 HTTP 400 `INVALID_URL`, 미지원 Udemy URL은 HTTP 422 `UNSUPPORTED`로 응답했다.
- URL 형식과 허용 호스트를 클라이언트와 서버에서 검사한다. 서버는 리다이렉트의 다음 목적지도 요청 전에 검사한다.
- 외부 요청은 전체 30초 제한과 최대 5회 리다이렉트 제한을 둔다. 오류 코드는 사용자에게 안내하고 상세 원인은 서버 로그에만 남긴다.
- `localStorage`를 읽을 때 계획별 형식을 검사해 손상된 계획을 제외한다.
- 자동 검증: 타입 검사, ESLint, 프로덕션 빌드 통과. Vitest 470개와 Playwright E2E 3개 통과. 자동 테스트는 실제 인프런 대신 저장된 응답을 사용한다.

## 배분 규칙 대조 실험

위의 실제 강의 5건에서 추출한 같은 목차를 두 규칙에 넣었다. **비교 기준**은 수업을 순서대로 더하다가 다음 수업을 더하면 하루 60분을 넘을 때 끊는 단순 규칙이다. **현재 규칙**은 60분에 가장 가까운 끊는 지점을 고르고, ±10분 안의 후보를 우선한다. 두 규칙 모두 수업을 쪼개지 않고, 영상 재생시간에 1.5배를 적용했다. 모든 요일은 60분 학습일이며 휴식일은 없다. 비교 기준은 실험을 위해 구현한 규칙으로, 과거 배포 버전의 실측값이 아니다.

| 강의 CID | 기준 규칙 학습일 | 기준 평균 절대 오차 | 현재 학습일 | 현재 평균 절대 오차 |
| --- | ---: | ---: | ---: | ---: |
| 344799 | 3일 | 6.79분 | 3일 | 8.14분 |
| 335806 | 4일 | 9.99분 | 4일 | 13.82분 |
| 327126 | 49일 | 10.73분 | 41일 | 5.90분 |
| 333662 | 25일 | 17.36분 | 17일 | 12.54분 |
| 326974 | 9일 | 16.96분 | 8일 | 14.01분 |

전체 학습일을 합쳐 계산한 하루 목표 60분과의 **평균 절대 오차는 13.03분에서 8.86분으로 32.0% 감소**했다. ±10분 안에 들어온 날은 기준 39/90일(43.3%), 현재 49/73일(67.1%)이다. 현재 규칙은 학습일 수도 90일에서 73일로 줄였다. 다만 강의 344799와 335806에서는 평균 오차가 늘었다. 수업을 쪼개지 않으므로 마지막 날의 짧은 분량이나 긴 수업의 영향이 남는다. 강의별 표본 수가 다르며, 이 결과를 모든 인프런 강의에 일반화할 수 없다.

개선율 계산은 `(13.03 - 8.86) / 13.03 × 100`이다. 반올림 전의 초 단위 합계는 기준 70,372.5초/90일, 현재 38,809.5초/73일이다. 사용자 작업 시간의 전후 비교는 아직 측정하지 않았다.
