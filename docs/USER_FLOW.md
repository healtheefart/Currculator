# 사용자 흐름 (0-mvp 프로토타입)

화면 기준은 `docs/design/prototype.dc.html`(1a 단계별 레이아웃)이다. 이 문서는 구현·테스트 기준이며, 유스케이스 ID(UC-xx, Ex)를 테스트 이름에 쓴다. 화면 문구는 이 문서와 프로토타입을 글자 그대로 따른다.

## 화면 구성
한 페이지(`/`) 안에서 상단 GlobalNav의 두 메뉴를 오간다. URL 경로는 바뀌지 않는다.
- **계획짜기**: 새 계획 만들기(4단계) 또는 저장한 계획 수정(3단계). 상단에 sticky 단계 바.
- **계획확인**: 저장한 계획 목록과 일정(목록/달력) 보기, 삭제, 수정 시작.

첫 화면: 저장한 계획이 있으면 계획확인, 없으면 계획짜기. 브랜드 "Currculator"를 누르면 계획짜기로 간다. 메뉴를 오가도 작성 중인 계획짜기 상태(메모리)는 유지된다. 새로고침하면 작성 중인 내용은 사라지고 저장한 계획만 남는다.

## 화면 상태
```
계획짜기(새 계획):
  type(학습 자료) → url(URL 입력) → [extracting] → edit(목차 확인) ⇄ schedule(일정 설정) → 계획하기 → 계획확인(새 계획 선택)
계획짜기(수정):
  계획확인 "계획 수정" → adjust(계획 수정) ⇄ edit ⇄ schedule → 저장 → 계획확인(그 계획 선택) / 취소 → 계획확인
```
- 단계 바: 새 계획은 `1 학습 자료 · 2 URL 입력 · 3 목차 확인 · 4 일정 설정`, 수정은 `계획 수정 중` 배지 + `1 목차 확인 · 2 일정 설정 · 3 계획 수정`.
- 단계 바 이동: 목차를 가져오기 전에는 지난 단계만 누를 수 있고 "학습 자료"로만 돌아간다(추출 중에는 불가). 목차를 가져온 뒤에는 목차 확인·일정 설정(수정이면 계획 수정까지)만 오갈 수 있다.
- 단계가 바뀌면 화면 맨 위로 스크롤한다.

## UC-01 학습 자료 고르기 (type 단계)
- 제목 "무엇으로 공부하나요?", 설명 "목차를 가져올 학습 자료를 고르세요."
- 카드 2개: "강의 커리큘럼"(설명 "온라인 강의 URL로 목차를 가져와요.") → url 단계. "책 목차"(설명 "ISBN으로 책의 목차와 쪽수를 가져와요.", 배지 "준비 중") → 카드가 선택 테두리로 바뀌고 "책 목차로 계획 짜기는 준비 중이에요. 지금은 강의 커리큘럼만 지원해요." 표시, 단계는 그대로.

## UC-02 URL로 목차 가져오기 (url 단계)
- "학습 자료 다시 고르기" 링크(추출 중에는 숨김), 제목 "강의 URL만 넣으세요.", 설명 "목차를 가져와 날짜별 학습 계획으로 나눠 드립니다."
- "강의 사이트" 칩: 인프런(기본 선택) / YouTube / 패스트캠퍼스 / 메가스터디. 지원하는 사이트만 보이며, 칩을 누르면 그 사이트가 선택되고 placeholder가 바뀐다. 지원하지 않는 사이트(Udemy·클래스101 등)는 칩을 두지 않는다(2026-11-03).
- 입력 + "목차 가져오기" 버튼. Enter도 제출. 입력을 바꾸면 오류 문구가 사라진다. placeholder는 선택한 사이트를 따른다: 인프런 `https://www.inflearn.com/course/...`, YouTube `https://www.youtube.com/playlist?list=...`, 패스트캠퍼스 `https://fastcampus.co.kr/...`, 메가스터디 `https://www.megastudy.net/teacher_v2/chr/lecture_detailview.asp?CHR_CD=...`.
- "예시 강의로 해보기" 링크 → 입력에 `https://www.inflearn.com/course/introduction-to-clau?cid=344799`를 채운다(추출 중에는 숨김).
- 추출 중: 입력·버튼 비활성, "강의 정보 가져오는 중…" + 경과 초(`3초`).
- 성공: 목차 확인 단계로. 시작일은 오늘(KST)로 다시 맞춘다. 다른 설정은 유지한다.
- 허용 입력(공통: scheme 없음(`https://` 보정) / 앞뒤 공백 / 해시):
  - 인프런: `?cid=` 있음 / cid 없는 slug(308 리다이렉트로 cid 붙음) / `/en/`·`/ja/`·`/vi/` 경로 / 추적 파라미터 / `inf.run` 단축 링크(301) / `m.inflearn.com`(→ `www`).
  - YouTube: `/playlist?list={id}` (`www.`·`m.`·`music.` 호스트 포함).
  - 패스트캠퍼스: `fastcampus.co.kr/{slug}`, `www.fastcampus.co.kr/{slug}` (`www.` 유무 모두 허용, 경로는 한 단계).
  - 메가스터디: `www.megastudy.net/teacher_v2/chr/lecture_detailview.asp?CHR_CD={숫자}`. 강좌 목록 링크(`/lecmain/{메뉴}/chr_detail/lecture_detailview.asp?CHR_CD=…`)와 `/chr/lecture_detailview.asp` 경로는 `/teacher_v2/chr/`로 정규화하고, `megastudy.net`은 `www.megastudy.net`으로 바꾼다.
- 예외:
  - E1 빈 값·URL 형식 아님 → `INVALID_URL` (클라이언트에서 판단, 서버 요청 없음)
  - E2 허용 호스트가 아닌 사이트, 플랫폼별 허용 경로가 아닌 주소(인프런 `/course/` 아님, YouTube `/playlist?list=` 아님, 패스트캠퍼스 두 단계 이상 경로, 메가스터디 `CHR_CD` 숫자 없음), `inf.run`이 강의가 아닌 곳으로 리다이렉트 → `UNSUPPORTED` (명백한 경우 클라이언트에서 먼저 판단)
  - E3 HTTP 404 → `NOT_FOUND`
  - E4 네트워크 오류·403/429/5xx·30초 초과·리다이렉트 루프 → `FETCH_FAILED` (입력 URL 유지, 다시 제출 가능)
  - E5 페이지에서 목차를 찾지 못함(인프런 `__NEXT_DATA__`·curriculum 쿼리 없음, 패스트캠퍼스 RSC payload에 curriculum 없음 — 강의가 아닌 페이지 포함, 메가스터디 강의목차 표 없음), 수업 0개 → `NO_CURRICULUM`
  - E6 요청 중 재제출 → 버튼 비활성·Enter 무시로 차단
  - E7 이미 계획을 만든 강의 → `ALREADY_PLANNED` + "계획확인에서 보기" 링크(그 계획을 선택한 계획확인으로 이동). 제출 전에 URL에서 알 수 있는 강의 id(인프런 `cid`, YouTube `youtube:{list}`, 메가스터디 `megastudy:{CHR_CD}`)가 저장한 계획의 `courseId`와 같으면 요청하지 않고 바로, 아니면 추출 후 `curriculum.courseId`로 다시 확인한다.

## UC-03 목차 확인 (edit 단계)
- 머리: "인프런 · {강사명}"(강사명이 없으면 "인프런"), 강의명(h1), "계획에 넣을 수업 {N}개 · 재생 {합} · 예상 {합×배수}".
- 안내: "{퀴즈·과제 N개는 목차에서 뺐어요.} 이미 들은 수업은 체크를 풀어 계획에서 빼세요." (뺀 개수가 0이면 앞 문장 생략)
- 시간 누락 수업이 있으면 검정 상자 "재생시간이 없는 수업이 {N}개 있어요. 입력하기 전까지 배분에서 빠집니다."
- 섹션 카드: "섹션 {n}" + 섹션명 + 섹션 예상 합. 표 머리 `추가 | 수업 | 재생(분) | 예상`.
- 수업 행: 체크박스(`aria-label="계획에 추가"`, 체크 = 포함), 제목 입력, 재생 분 입력(누락이면 비어 있고 placeholder "—"), 예상 시간(제외·누락이면 "—"). 배지 "시간 누락"(포함된 누락 수업) / "직접 입력"(사용자가 시간을 입력).
- 체크 해제한 수업: pearl 배경, 회색 취소선 제목, 배분·합계에서 빠짐.
- 예외(입력값은 그대로 보이고 상태는 이전 값 유지, 입력 테두리 2px 검정):
  - 빈 제목 → "제목을 비울 수 없어요"
  - 재생 분이 0~1440 정수가 아님 → "0~1440 사이 분으로 입력해 주세요"
- 하단 버튼: 새 계획 `처음부터`(확인창) · `일정 설정` / 수정 `취소` · `일정 설정`.

## UC-04 일정 설정 (schedule 단계)
- 제목 "일정 설정", 카드 하나에:
  - "요일별 가용 시간 (분, 0 = 쉬는 요일)": 프리셋 칩(매일 60분 / 평일만 60분 / 평일 60분·주말 120분, 현재 값과 같으면 선택 표시) + 월~일 7칸 입력(0분 요일은 parchment 배경).
  - "허용 오차": "하루 ±[10]분까지 괜찮아요".
  - "예상 학습시간": "재생시간 ×[1.5]".
  - "시작일": 날짜 입력.
  - "휴식일": 설명 "날짜를 눌러 휴식일로 지정하거나 해제하세요. 쉬는 요일과 시작일 이전은 고를 수 없어요." + 월 달력(이전/다음 달, 기본은 시작일의 달) + 선택한 휴식일 칩("11월 5일 (수)" + ×로 삭제).
- 기본값: 시작일 오늘(KST), 매일 60분, 허용 오차 10분, 배수 1.5, 휴식일 없음.
- 예외(상태는 이전 값 유지):
  - 모든 요일 0분 → "학습할 요일을 하나 이상 정해 주세요."
  - 요일 분이 0~1440 정수가 아님 → "0~1440 사이 숫자로 입력해 주세요. 이전 값을 유지합니다."
  - 오차가 0~1440 정수가 아님, 배수가 0.5~5가 아님 → "오차는 0 이상, 배수는 0.5~5 사이로 입력해 주세요. 이전 값을 유지합니다."
- 하단 버튼: 새 계획 `이전` · `계획하기` / 수정 `이전` · `계획 수정`. 계획을 만들 수 없으면(`NO_STUDY_DAYS`, `NO_ITEMS`) `계획하기`는 비활성이고 버튼 아래에 사유 문구를 보인다.
- `계획하기` → 계획을 저장하고 계획확인으로 이동해 새 계획을 선택한다. 계획짜기 상태는 처음(type 단계)으로 초기화한다.

## UC-05 계획 보기 (계획확인)
- 저장한 계획이 없으면: "저장한 계획이 없어요." / "계획짜기에서 강의를 불러와 계획을 만들면 여기에 모입니다." / `계획짜기` 버튼.
- 제목 "계획확인" + 계획 선택 목록(`listbox`):
  - 첫 행 "전체 계획" / "저장한 계획 {N}개를 날짜별로 함께 보기" (기본 선택)
  - 계획마다 강의명 / "{첫 학습일} ~ {마지막 학습일} · 학습일 {N}일 · 예상 {합}" (배정된 날이 없으면 "배정된 수업 없음")
- 요약 카드: 제목(강의명 또는 "전체 계획"), 전체면 "계획 {N}개", "예상 {합}", "{시작} ~ {끝}", "학습일 {N}일", "경고 {N}일"(1 이상이면 굵게).
- 일정 섹션: 제목 "일정"(계획 하나) / "날짜별 전체 일정"(전체) + 탭 칩 `목록` · `달력`(기본 목록, 선택은 메뉴를 오가도 유지).
- 전체 계획: 모든 계획의 날짜별 결과를 날짜로 합친다. 같은 날 수업은 계획 저장 순서대로, 수업 위 라벨은 "{강의명} · {섹션명}", 그날 합계는 각 계획 합의 합, 하나라도 범위 밖이면 그날 경고("허용 범위 밖"만 표시).
- 계획 하나를 선택하면 하단에 `삭제`(확인창 "이 계획을 삭제할까요?" / "삭제한 계획은 되돌릴 수 없어요." / `삭제`) · `계획 수정`. 하단 안내 "저장한 계획은 이 브라우저에 보관됩니다."

### 목록 보기
- 날짜 행: "11월 3일 (화)", 그날 예상 합, 오늘이면 "오늘" 배지와 pearl 배경.
- 수업: 섹션 라벨(fine-print) + 제목 + 예상 시간. 수업이 없는 날은 "배정된 수업 없음".
- 범위 밖: "허용 범위 밖 · 목표 {가용} / 실제 {합}".

### 달력 보기
- 월 제목 "2026년 11월", 이전/다음 달 버튼(범위 제한 없음), 일~토 머리.
- 칸: 날짜 숫자(오늘은 파란 원), 범위 밖 점, 오른쪽에 그날 합계, 수업 제목 최대 3개 + "+{나머지}".
- 첫 화면의 달: 오늘이 계획 기간(첫 날~마지막 날) 안이면 오늘의 달, 아니면 계획 하나는 시작일의 달 / 전체는 첫 학습일의 달 / 계획짜기에서는 시작일의 달.
- 날짜를 누르면 아래에 상세: "11월 3일 (화)" + "예상 {합}", 번호 매긴 수업 목록(섹션 라벨·예상), 범위 밖 배지. 수업이 없으면 "이 날은 배정된 수업이 없어요."
- 기본 선택: 보이는 달에 오늘이 있고 수업이 있으면 오늘, 아니면 그 달의 첫 수업 날. 달을 바꾸면 선택을 기본으로 되돌린다.
- 안내: "● 허용 범위 밖 · 날짜를 누르면 그날 들을 수업이 아래에 표시됩니다."

## UC-06 계획 수정 (수정 모드)
- 계획확인에서 `계획 수정` → 계획짜기 메뉴, adjust 단계. 저장본을 복사해 편집하며 `저장` 전까지 저장본은 바뀌지 않는다.
- adjust 단계: 요약 카드 + 제목 "계획 수정" + 목록/달력 탭. 목록에서만 편집한다.
  - 안내: "수업을 끌어 다른 날짜에 놓으면 일정이 바뀝니다. 끌기 어려우면 수업을 눌러 선택한 뒤 옮길 날짜를 고르세요. ×를 누르면 계획에서 빠집니다." (수업을 선택한 동안은 "옮길 날짜에서 \"여기로 옮기기\"를 누르세요. 같은 수업을 다시 누르면 선택이 풀려요.")
  - 끌어서 놓기: 수업을 다른 날짜 행에 놓으면 그 날짜로 옮긴다.
  - 눌러 옮기기: 수업을 누르면 선택되고, 다른 날짜 행마다 `여기로 옮기기` 버튼이 생긴다. 같은 수업을 다시 누르면 선택 해제.
  - 옮긴 수업에는 "직접 옮김" 배지. 원래 배정 날짜로 되돌리면 옮김 기록이 사라진다.
  - × (`aria-label="계획에서 제외"`) → 계획에서 빠지고 아래 "제외한 수업 {N}개" 카드에 나타난다. `다시 넣기`로 되돌린다.
  - 옮김·제외가 하나라도 있으면 `자동 배분으로 되돌리기` 링크 → 모두 지운다.
  - 같은 날 수업은 목차 순서로 정렬한다. 날짜 합계·범위 밖 여부는 옮긴 뒤 다시 계산한다.
- 하단 버튼: adjust `일정 설정` · `취소` · `저장`, edit `취소` · `일정 설정`, schedule `이전` · `계획 수정`. 안내 "저장을 눌러야 변경 내용이 반영돼요."
- `저장` → 저장본을 바꾸고 계획확인에서 그 계획을 선택. `취소` → 변경을 버리고 계획확인.
- 목차·설정을 바꾸면 자동 배분은 다시 계산되고, 옮긴 수업은 지정한 날짜에 그대로 둔다. 목차에서 체크를 푼 수업의 옮김·제외 기록은 무시한다.

## UC-08 저장·복원
- 저장 키 `currculator:plans:v1`, 값 `{version: 1, plans: SavedPlan[]}`. 계획하기·저장·삭제 때만 쓴다. 앱을 열거나 읽을 때는 쓰지 않는다(손상된 저장본을 덮어쓰지 않음).
- 읽을 때 계획마다 필드를 검증하고 새 객체로 다시 만든다. 잘못된 계획은 그 계획만 버린다. JSON 손상·버전 불일치 → 빈 목록.
- localStorage 사용 불가(사생활 모드 등) → 저장 없이 정상 동작.
- 렌더링 중 예외 → `error.tsx`의 "문제가 생겼어요" + "저장된 계획 지우고 다시 시작".

## 배분 규칙 (buildPlan)
1. 배정 대상: level 1, 제외 아님, durationSec > 0. 예상 시간 = durationSec × 배수.
2. 시작일부터 학습일(가용 분 > 0인 요일, 휴식일 아님)마다 남은 수업을 순서대로 누적한다.
3. 누적이 `[가용−N, 가용+N]`(하한은 최소 0) 안에 드는 끊는 지점 중 가용에 가장 가까운 곳에서 끊는다. 동률이면 짧은 쪽.
4. 범위 안 지점이 없으면 범위 밖이라도 가장 가까운 지점에서 끊고 `outOfRange: true`.
5. 학습일마다 최소 1개 배정(하루보다 긴 수업은 통째로). 따라서 학습일 수 ≤ 수업 수.
6. 총량 보존, 목차 순서 유지.
- 예시(가용 60, 오차 10): 25·20·18·30 → 63분에서 끊음 / 25·20·40 → 45분, 경고 / 80 단일 → 통째, 경고 / 55와 65 동률 → 55.
- 실패 사유: 모든 요일 0분 → `NO_STUDY_DAYS`, 배정 대상 0개 → `NO_ITEMS`.

## 직접 조정 규칙 (applyOverrides)
- 입력: buildPlan 결과 + `overrides: Record<수업 id, IsoDate | null>`(날짜 = 옮김, null = 제외).
- 자동 배분 결과에 없는 수업 id의 기록은 무시한다.
- 옮긴 수업은 원래 날짜에서 빼고 지정 날짜에 넣는다. 지정 날짜가 자동 배분 날짜에 없으면 새 날을 만든다(목표 = 그 요일 가용 분).
- 날짜는 오름차순, 같은 날 수업은 목차 순서. 날마다 합계·`outOfRange`를 다시 계산한다(수업이 없는 날은 경고 없음). 수업이 모두 빠진 날도 목록에 남는다("배정된 수업 없음").
- 제외한 수업은 `removedItemIds`로 따로 돌려준다.
