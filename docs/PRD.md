# PRD: Currculator

## 목표
사용자가 강의 URL을 입력하면, 목차를 자동으로 추출해 바로 실행할 수 있는 일자별 학습 계획을 받는다. 추출이 오래 걸려도 진행 상황이 계속 보여야 한다.

## 사용자
온라인 강의(인프런, Udemy 등)나 전공·기술 서적으로 혼자 공부하는 성인(직장인, 취업 준비생).

## 해결할 문제
강의나 책의 목차를 보고 날짜별로 분량을 나누는 일이 번거롭고 시간이 오래 걸린다.

## 전체 기능 (MVP 전체 범위)
1. URL 입력과 목차 추출: 강의 플랫폼 전용 추출기(인프런·YouTube 재생목록·패스트캠퍼스·메가스터디. Udemy는 봇 차단, 클래스101·에듀윌은 공개 목차 확인 불가로 제외), 책 ISBN 파이프라인, 그 밖의 URL은 LLM 구조화
2. 목차 확인·편집: 제목·재생시간·시작 쪽수 수정, 누락 분량 보완, 출처 표시
3. 예상 학습시간 환산: 강의 재생시간 ×1.5, 책 쪽당 2분 (둘 다 조정 가능)
4. 학습 일정 설정과 계획 생성: 학습 요일, 요일별 가용 시간, 허용 오차, 휴식일, 시작일
5. 계획 미리보기: 날짜별 목록과 월간 달력 탭 (로그인 불필요)
6. 로그인(Google·Kakao·Naver)과 계획 저장, 완료 체크·진도율, 수동 편집, 밀린 분량 재조정
7. 추출 캐시, ISBN별 시작 쪽수 익명 공유

## 단계별 범위
| phase | 범위 |
|---|---|
| **0-mvp** (현재, 프로토타입) | 프로젝트 세팅, 계획짜기 단계 흐름(학습 자료 선택 → URL 입력 → 목차 확인 → 일정 설정), 인프런 추출(진행 표시), 목차 편집(제목·시간·수업 제외), 예상 학습시간 환산, 하루 분량 모드 배분(요일별 가용 시간 + 허용 오차, 휴식일 달력, 프리셋), 여러 계획 저장(localStorage)과 계획확인(계획별·전체 보기, 목록·월간 달력, 삭제), 저장한 계획 수정(수업 직접 옮기기·제외 포함), 강의당 계획 1개. 화면은 `docs/design/prototype.dc.html`, 상세 흐름은 `docs/USER_FLOW.md` |
| 이후 | CI·Vercel 배포 → YouTube·패스트캠퍼스·메가스터디(1-course-platforms 완료) → 책 파이프라인 → LLM 범용 추출 → 로그인·저장·관리 → 캐시·쪽수 공유 → 자동 추천·목표 종료일 모드 |

### 0-mvp에서 제외
- CI(GitHub Actions)와 Vercel 배포
- 로그인, 서버 저장, 완료 체크, 밀린 분량 재조정
- 목차 직접 입력(추출 실패·미지원 URL은 안내 문구만)
- 인프런 외 강의 플랫폼, 책, LLM 추출 (1-course-platforms에서 YouTube·패스트캠퍼스·메가스터디를 추가했다. 지원하지 않는 사이트는 화면에 두지 않는다)
- 자동 추천 모드, 목표 종료일 모드
- 섹션 쪼개기(항목 분할)

## MVP 제외 사항
- 외부 내보내기와 캘린더 연동(ICS, 구글 캘린더, CSV, 노션)
- 소셜·공유 기능(계획 공유, 스터디 그룹)
- URL 외 입력 방식(텍스트 붙여넣기, 이미지 OCR, PDF·EPUB 업로드). 단, 추출 실패 시 목차 직접 입력은 포함한다.
- 알림(푸시, 이메일)
- 콜로소 지원

## 확정 규칙
### 배분 (하루 분량 모드)
- 사용자는 요일별 가용 시간과 허용 오차 ±N분(기본 10분, 모든 학습일에 동일)을 먼저 설정한다. 기본값은 매일 60분이고, 프리셋(매일 60분 / 평일만 60분 / 평일 60분·주말 120분)으로 한 번에 바꿀 수 있다.
- 날짜마다 목차 순서대로 수업을 쌓고, 누적 합계가 `[가용−N, 가용+N]` 안에 드는 끊는 지점 중 가용 시간에 가장 가까운 지점에서 그날을 끝낸다. 두 지점이 똑같이 가까우면 짧은 쪽을 고른다.
- 범위 안에 끊을 지점이 없으면 범위 밖이라도 가장 가까운 지점에서 끊고, 그 날짜에 "허용 범위 밖" 경고를 표시한다.
- 하루보다 긴 수업 하나는 통째로 하루에 배정한다(무한 이월 방지). 수업을 쪼개지 않는다.
- 원래 목차 순서는 항상 유지한다. 휴식일과 학습하지 않는 요일에는 배정하지 않는다.
- 예시(가용 60분, 오차 10분): 수업 25·20·18·30분 → 누적 63분에서 끊음 / 수업 25·20·40분 → 45분에서 끊고 경고 / 80분 수업 하나 → 통째로 배정하고 경고

### 목차
- 섹션(level 0)은 묶음 제목이며 배정·진도율 단위가 아니다. 배정 단위는 수업(level 1)이다.
- 영상이 아닌 수업(퀴즈, 과제 등, 인프런 `type !== "LECTURE"`)은 목차와 진도율에서 제외한다.
- 영상 수업인데 재생시간이 0이면 "시간 누락"으로 강조하고 사용자가 입력하게 한다.
- 사용자는 이미 들은 수업을 수업별 "제외" 체크로 배분에서 뺄 수 있다.

### 저장
- 0-mvp는 사용자가 만든 계획 여러 개를 이 브라우저(localStorage)에 저장한다. "계획하기"·"저장"·"삭제"를 누를 때만 저장하며, 작성 중인 내용은 저장하지 않는다.
- 강의 하나에는 계획 하나만 만든다(인프런 강의 id 기준). 이미 있으면 기존 계획을 수정하도록 안내한다.

### 직접 조정
- 저장한 계획을 수정할 때 수업을 다른 날짜로 옮기거나(끌어서 놓기 또는 눌러 옮기기) 계획에서 뺄 수 있다. 옮긴 수업은 "직접 옮김"으로 표시하고, "자동 배분으로 되돌리기"로 모두 취소할 수 있다.

### 시간·날짜
- 강의 예상 학습시간 = 재생시간 × 1.5 (배수는 사용자가 조정 가능, 양수).
- 날짜와 "오늘"은 한국 시간(Asia/Seoul) 기준이다.
- 표시 시간은 분 단위 반올림(예: `1시간 25분`).
- 진도율 = 완료 항목 수 ÷ 전체 항목 수 × 100 (저장 기능 phase부터 적용).

### 진행 상황
- 추출 시간에 상한 목표를 두지 않는다. 대신 요청 중에는 "강의 정보 가져오는 중…"과 경과 초를 계속 보여 준다. (외부 요청에는 멈춤 방지용 30초 타임아웃만 둔다.)
