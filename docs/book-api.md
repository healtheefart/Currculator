# 책 목차 검색 설정

책 검색은 국립중앙도서관 ISBN 서지정보 Open API를 사용합니다. API 키를 발급한 뒤 프로젝트 루트의 `.env.local`에 아래 값을 설정하고 개발 서버를 다시 시작하세요.

```env
NL_API_CERT_KEY=발급받은_API_키
```

검색은 책 제목 또는 ISBN으로 할 수 있습니다. 목차 데이터가 있는 책은 목차 항목별 시작 페이지를 읽고, 다음 목차의 시작 페이지 직전까지를 해당 항목의 범위로 계산합니다. 예상 학습시간은 페이지당 2분을 기준으로 하며 일정 설정에서 배수를 조정할 수 있습니다.

국립중앙도서관 안내에 따르면 API의 목차 파일 URL은 2021년 2월까지 생성된 데이터이며, 책에 따라 목차나 페이지 정보가 없을 수 있습니다. [ISBN 서지정보 Open API 안내](https://www.nl.go.kr/NL/contents/N31101030500.do)
